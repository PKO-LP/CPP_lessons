# Этап 68. Добавьте безопасное удаление и поиск

[← Этап 67](67.md) · [Оглавление](../README.md) · [Этап 69 →](69.md)

Добавьте к своему менеджеру задач ещё две возможности.

**Команда 5 — удалить последнюю задачу.** Программа сообщает название удалённой задачи и оставшееся количество. Если список пуст, выводится понятное сообщение, работа меню продолжается.

**Команда 6 — найти задачу по названию.** При совпадении программа сообщает позицию первого найденного элемента. При отсутствии совпадений сообщает, что задача не найдена. Учитывайте регистр букв.

Проверьте:

1. Удаление из списка с несколькими задачами.
2. Удаление единственной задачи.
3. Повторное удаление из пустого списка.
4. Поиск первого, среднего и последнего элемента.
5. Поиск отсутствующего названия.
6. Поиск в пустом списке.

Дополнительное задание: разрешите названия из нескольких слов при добавлении и поиске.

Сдайте собственный исходник и результаты проверок. Будьте готовы объяснить, какой именно цикл завершает команда break в вашем поиске.
