# Этап 67. Добавьте обратный показ и количество задач

[← Этап 66](66.md) · [Оглавление](../README.md) · [Этап 68 →](68.md)

Добавьте к менеджеру задач две возможности:

1. Команда 3 показывает задачи в обратном порядке с их исходными номерами.
2. Команда 4 показывает текущее количество задач.
3. После обратного показа порядок хранения задач должен оставаться прежним.
4. Программа корректно обрабатывает пустой список.
5. После выполнения команды меню появляется снова.

Измените меню, реализуйте обе команды и запустите программу. Проверьте её сначала на исходном списке, затем после добавления новой задачи, затем на пустом списке.

Сдайте собственный исходник и описание результатов проверок. На защите объясните выбор начального индекса, границы и шага обратного цикла.
