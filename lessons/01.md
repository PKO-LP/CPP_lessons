# Этап 1. Найдите редактор и кнопку запуска

[Оглавление](../README.md) · [Этап 2 →](02.md)

1. Откройте сайт по ссылке выше.
2. Убедитесь, что открыта страница Online C++ Compiler. Язык уже выбран ссылкой.
3. Найдите редактор main.cpp и кнопку Run. Дополнительный выбор стандарта для этих примеров не требуется.
4. Найдите область Output. Здесь появится результат или сообщение об ошибке.
5. Для упражнений с cin вводите данные прямо в Output после появления приглашения.
6. Найдите меню с тремя точками рядом с областью Output: пункт Download понадобится для сохранения версии.

Вверху находится редактор main.cpp, рядом или ниже — Output. На узком экране между main.cpp и Output можно переключаться вкладками. В примерах с вводом щёлкайте в Output и нажимайте Enter после каждого значения. Сейчас вводить ничего не нужно: первая программа только печатает сообщение.

**Контроль:** покажите преподавателю редактор, Run и область результата.
