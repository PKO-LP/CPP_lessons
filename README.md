# C++ с нуля в Programiz

Пошаговый практикум: от первой программы, переменных и типов данных до циклов, коллекций, функций и собственного менеджера задач проекта.

## Как работать

1. Откройте [онлайн-компилятор Programiz](https://www.programiz.com/cpp-programming/online-compiler/).
2. Переходите к урокам по оглавлению ниже.
3. Набирайте учебные программы с картинок вручную. Номера строк слева вводить не нужно.
4. Каждый показанный пример — полная самостоятельная программа: наберите все его части по порядку, затем нажмите Run.
5. Под каждой картинкой находятся объяснения элементов и назначения строк. Прочитайте их и выполните самостоятельные изменения.
6. Сначала предскажите результат, затем запустите программу и сравните.
7. Сохраняйте собственные исходники с расширением .cpp и записывайте результаты проверок.

Картинки имеют одинаковый размер 1600 × 1000 пикселей и крупный шрифт. Если изображение уменьшилось в узком окне, откройте его отдельно и увеличьте масштаб.

Финальные этапы выполняются самостоятельно: готовые решения к ним не приводятся.
